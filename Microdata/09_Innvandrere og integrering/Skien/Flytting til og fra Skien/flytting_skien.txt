# Flytting til og fra Skien

Analyse av innenlands flytting til og fra Skien kommune, for hele befolkningen,
innvandrere, sekundærbosatte flyktninger og familieinnvandrede til disse.

**Grupper:**
1. **Innflyttere**: bodde i en annen norsk kommune og flyttet til Skien i perioden
2. **Utflyttere**: bodde i Skien og flyttet til en annen norsk kommune i perioden
3. **Innvandrere** (innvandringskategori B) blant inn- og utflytterne
4. **Sekundærbosatte**: innvandrere blant innflytterne med innvandringsgrunn Flukt og botid i
   Norge på 10 år eller mindre ved innflytting. Siden innflytterne per definisjon bodde i en
   annen norsk kommune før Skien, har de alle vært bosatt i minst én annen kommune tidligere.
5. **Familieinnvandrede til de sekundærbosatte**: innvandringsgrunn Familie, kom til Skien
   (innenlands eller direkte fra utlandet) samme år som eller etter en person i gruppe 4,
   og tilhører samme familie (familienummer) som denne

**Metode:** Bostedskommune hentes per 1.1. hvert år. En *flytting* i kalenderår t betyr
at bostedskommunen 1.1.t er en annen enn 1.1.(t+1). Bare innenlands flytting er med:
personer som innvandret direkte fra utlandet til Skien regnes ikke som innflyttere.
Alle kommunenumre er omkodet til 2024-inndelingen (for eksempel Skien 0806/3807 -> 4003,
Bø/Sauherad 0821/0822/3817 -> Midt-Telemark 4020).

Personvern: microdata.no legger støy på og skjuler små celler. Bruk grove inndelinger.
endblock

// ============================================================================
// 3. FLYTTINGER: identifiser inn- og utflyttinger per år
// ============================================================================
// For hvert intervall 1.1.(aar-1) -> 1.1.aar:
//   inn_aar = 1: bodde i en annen norsk kommune 1.1.(aar-1) og i Skien 1.1.aar
//   ut_aar  = 1: bodde i Skien 1.1.(aar-1) og i en annen norsk kommune 1.1.aar
// Krav om gyldig kommune på begge tidspunkt sørger for at bare innenlands flytting
// telles (innvandring fra utlandet, utvandring, fødsel og død faller utenfor).
//
// Per person lagres FØRSTE inn- og utflytting i perioden:
//   inn_flytteaar / ut_flytteaar : kalenderåret flyttingen skjedde (0 = ingen flytting)
//   fra_kommune / til_kommune    : kommunen personen flyttet fra / til (0 = ingen flytting)

generate inn_flytteaar = 0
generate ut_flytteaar = 0
generate fra_kommune = 0
generate til_kommune = 0
generate antall_inn = 0
generate antall_ut = 0

for aar in $aar1 : $sluttaar
    let forrige = $aar - 1
    let vf = bosted_ ++ $forrige
    let v = bosted_ ++ $aar
    let inn = inn_ ++ $aar
    let ut = ut_ ++ $aar

    generate $inn = !sysmiss($vf) & !sysmiss($v) & $vf != $skien & $v == $skien
    generate $ut = !sysmiss($vf) & !sysmiss($v) & $vf == $skien & $v != $skien

    // Første innflytting / utflytting i perioden
    // (rekkefølgen er viktig: kommune settes før flytteår, siden flytteår brukes i betingelsen)
    replace fra_kommune = $vf if $inn == 1 & inn_flytteaar == 0
    replace inn_flytteaar = $forrige if $inn == 1 & inn_flytteaar == 0
    replace til_kommune = $v if $ut == 1 & ut_flytteaar == 0
    replace ut_flytteaar = $forrige if $ut == 1 & ut_flytteaar == 0

    // Antall flyttinger per person (noen flytter inn og ut flere ganger)
    replace antall_inn = antall_inn + $inn
    replace antall_ut = antall_ut + $ut
end

// Sekundærbosatt = innflytter (bodde i en annen norsk kommune 1.1. før flyttingen, jf. del 3)

// ============================================================================
// 7. FAMILIEINNVANDREDE TIL DE SEKUNDÆRBOSATTE (gruppe 5)
// ============================================================================
// Kobling via familienummer (BEFOLKNING_REGSTAT_FAMNR: personer med samme nummer tilhører
// samme registerbaserte familie, dvs. par og deres ugifte barn som bor sammen). Familie er
// snevrere enn husholdning og passer bedre for familiegjenforening (ektefelle/barn/foreldre
// til mindreårige). For en bredere kobling kan BEFOLKNING_HUSHNR brukes i stedet.
//
// For hvert år:
//   1) Tell sekundærbosatte per familie som hadde flyttet til Skien senest i fjor og bor i
//      Skien 1.1. i år (aggregate på hele datasettet, ingen keep).
//   2) En familieinnvandret (inngrunn = FAM) regnes til gruppe 5 hvis personen kom til Skien
//      i fjor, enten ved innenlands flytting ($inn) eller direkte fra utlandet ($ny: ikke
//      bosatt i Norge 1.1. i fjor, første opphold i fjor), og tilhører en slik familie.
// Dermed er kravet "kom samtidig med eller etter den sekundærbosatte" oppfylt.
// Merk: INNGRUNN1 = FAM omfatter både familiegjenforening og familieetablering, og koblingen
// sier at personene bor sammen, ikke at familieinnvandringen gjaldt akkurat denne personen.

// Største familie som regnes som en ekte familie (se kommentar om familienummer i løkken)
let maks_famstr = 20

generate en_pers = 1
generate familieinnvandret = 0
generate fam_flytteaar = 0
generate fam_fra_utlandet = 0

for aar in $aar1 : $sluttaar
    let forrige = $aar - 1
    let d = date_fmt($aar)
    let vf = bosted_ ++ $forrige
    let v = bosted_ ++ $aar
    let inn = inn_ ++ $aar
    let f = famnr_ ++ $aar
    let es = en_sek_ ++ $aar
    let nf = n_sek_ ++ $aar
    let ny = ny_ ++ $aar
    let fa = fam_ ++ $aar
    let fs = famstr_ ++ $aar

    import db/BEFOLKNING_REGSTAT_FAMNR $d as $f

    // 1) Sekundærbosatte i Skien per 1.1.aar, talt per familie
    generate $es = sekundærbosatt == 1 & inn_flytteaar <= $forrige & !sysmiss($v) & $v == $skien
    aggregate (sum) $es -> $nf, by($f)

    // Familienummeret er en pseudonymvariabel og kan bare brukes som nøkkel (by/on), ikke i
    // uttrykk som sysmiss(). Personer uten familienummer havner i én stor felles gruppe, som
    // holdes utenfor med kravet om at familien har maks_famstr personer eller færre.
    aggregate (sum) en_pers -> $fs, by($f)

    // 2) Familieinnvandrede som kom til Skien i fjor og tilhører en slik familie
    generate $ny = sysmiss($vf) & !sysmiss($v) & $v == $skien & !sysmiss(forst_aar) & forst_aar == $forrige
    generate $fa = innvandrer == 1 & inngrunn == 'FAM' & ($inn == 1 | $ny == 1) & $fs <= $maks_famstr & $nf >= 1

    // Første år personen oppfyller kravene (formler, ikke replace ... if)
    replace fam_flytteaar = fam_flytteaar + $forrige * $fa * (familieinnvandret == 0)
    replace fam_fra_utlandet = fam_fra_utlandet + $ny * $fa * (familieinnvandret == 0)
    replace familieinnvandret = familieinnvandret + $fa * (familieinnvandret == 0)
end

// Alder ved ankomst til Skien (alder_inn finnes bare for innenlands innflyttere)
generate alder_fam = fam_flytteaar - fodselsaar if familieinnvandret == 1
// Aldersgrupper med formel, ikke recode: gruppen er liten, og recode stoppes av
// avsløringskontrollen når en målverdi (f.eks. 0-5 år) rammer for få personer.
generate aldersgruppe_fam = 1 + (alder_fam >= 6) + (alder_fam >= 16) + (alder_fam >= 20) + (alder_fam >= 25) + (alder_fam >= 30) + (alder_fam >= 40) + (alder_fam >= 50) + (alder_fam >= 67) if familieinnvandret == 1
define-labels alderfamlbl \
    1 '0-5 år' 2 '6-15 år' 3 '16-19 år' 4 '20-24 år' 5 '25-29 år' \
    6 '30-39 år' 7 '40-49 år' 8 '50-66 år' 9 '67 år og eldre'
assign-labels aldersgruppe_fam alderfamlbl
define-labels utllbl 0 'Innenlands flytting' 1 'Direkte fra utlandet'
assign-labels fam_fra_utlandet utllbl
