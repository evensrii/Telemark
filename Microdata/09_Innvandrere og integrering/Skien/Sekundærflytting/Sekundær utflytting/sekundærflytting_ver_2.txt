# Sekundærflytting av flyktninger til Skien

Kartlegger flyktninger som har flyttet til Skien fra en annen norsk kommune, og om Skien
er deres **andre bosettingskommune** (sekundærbosetting).

**Populasjon:** innvandrere (INVKAT = B) med innvandringsgrunn Flukt (FLU) og første
oppholdsdato i Norge 1.1.1992 eller senere (slik at hele bostedshistorikken er dekket).

**Kilde for bosted:** BOSATTEFDT_BOSTED (bostedskommune i forløp med eksakte datoer, 1992-2024).

**Mottaksregel:** Mange registreres først i kommunen der asylmottaket ligger, og bosettes
av IMDi i en annen kommune kort tid etter. Er første bostedsperiode kortere enn
mottak_mnd måneder og personen har en neste periode, regnes første periode som mottak
og neste kommune som **bosettingskommunen**. Følsomhet vises for 3, 6 og 12 måneder.

**Kategorier for første flytting til Skien i perioden:**
1. *Første bosetting:* Skien er bosettingskommunen (kom fra mottakskommune). Ikke sekundærflytting.
2. *Skien som kommune nr. 2:* én bosettingskommune før Skien. Hovedtallet.
3. *Skien som kommune nr. 3 eller senere*
4. *Tilbakeflytter:* har vært bosatt i Skien tidligere (etter bosetting).

Personvern: microdata.no legger støy på og skjuler små celler. Bruk grove inndelinger.
endblock

Antall ekte bostedsperioder (etter at kunstige perioder ved kodeendring er fjernet),

tabulate n_perioder
tabulate n_kunstige
tabulate over_maks

// ---- 3b. Varighet av første periode og mottaksregelen -----------------------
generate varighet1_mnd = (start_2 - start_1) / 30.44
generate varighet1_gr = 9
replace varighet1_gr = 1 if varighet1_mnd < 3
replace varighet1_gr = 2 if varighet1_mnd >= 3 & varighet1_mnd < 6
replace varighet1_gr = 3 if varighet1_mnd >= 6 & varighet1_mnd < 12
replace varighet1_gr = 4 if varighet1_mnd >= 12 & varighet1_mnd < 24
replace varighet1_gr = 5 if varighet1_mnd >= 24 & !sysmiss(varighet1_mnd)
define-labels varighetlbl \
    1 'Under 3 mnd' 2 '3-5 mnd' 3 '6-11 mnd' 4 '12-23 mnd' 5 '24 mnd eller mer' 9 'Bare én periode (aldri flyttet)'
assign-labels varighet1_gr varighetlbl

generate kom1_skien = kom_1 == $skien

textblock
## 3.2 Varighet av første bostedsperiode (etter fjerning av kunstige perioder)
En tydelig klynge av korte første perioder tyder på registrering i mottakskommune før bosetting.
Andre tabell: første periode i Skien (1) eller i en annen kommune (0).
endblock
tabulate varighet1_gr
tabulate varighet1_gr kom1_skien


// ============================================================================
// 4. FLYTTING TIL SKIEN OG KATEGORISERING
// ============================================================================

// ---- 4a. Skien-flytting (beregnet i forløpet, del 2c) ------------------------
// skien_idx = 0: ikke flyttet til Skien i perioden.
// tidl_skien_fra1/2: har bodd i Skien før flyttingen, fra og med periode 1 / periode 2.
replace skien_idx = 0 if sysmiss(skien_idx)

// ---- 4c. Bosettingskommune og kategori for hver mottaksgrense (3, 6, 12 mnd) -
// Beregnes med én generate per variabel (ikke replace), for å unngå at avsløringskontrollen
// stopper operasjoner som rammer få personer.
//   bos_idx: 2 hvis periode 1 var kortere enn x måneder (mottak), ellers 1
//   tidl:    tidligere bosatt i Skien etter bosetting (fra bosettingsperioden)
//   kategori: 1 = Skien er bosettingskommunen, 2 = Skien rett etter bosettingskommunen,
//             3 = Skien senere, 4 = som 3 men har bodd i Skien før (tilbakeflytter)
define-labels katlbl \
    0 'Ikke flyttet til Skien i perioden' \
    1 'Første bosetting (fra mottakskommune)' \
    2 'Skien som kommune nr. 2' \
    3 'Skien som kommune nr. 3 eller senere' \
    4 'Tilbakeflytter til Skien'

for x in 3 6 12
    let b = bos_idx_ ++ $x
    let t = tidl_ ++ $x
    let kt = kategori_ ++ $x
    generate $b = 1 + (!sysmiss(start_2) & varighet1_mnd < $x)
    generate $t = ($b == 1) * tidl_skien_fra1 + ($b == 2) * tidl_skien_fra2
    generate $kt = (skien_idx > 0) * ((skien_idx == $b) * 1 + (skien_idx == $b + 1) * 2 + (skien_idx >= $b + 2) * (3 + $t))
    assign-labels $kt katlbl
end

// Hovedregel (mottak_mnd)
let hoved_b = bos_idx_ ++ $mottak_mnd
let hoved_k = kategori_ ++ $mottak_mnd
generate bos_idx = $hoved_b
generate kategori = $hoved_k
assign-labels kategori katlbl

// ---- 4d. Flyttedato, fraflyttingskommune, bosettingskommune og botid ---------
// flyttedato og fra_kommune er beregnet i forløpet (del 2c)
generate flytteaar = year(flyttedato) if skien_idx > 0
generate fra_fylke = int(fra_kommune / 100)
assign-labels fra_kommune kommunelbl
assign-labels fra_fylke fylkelbl

generate bos_kommune = kom_1
replace bos_kommune = kom_2 if bos_idx == 2
generate bos_dato = start_1
replace bos_dato = start_2 if bos_idx == 2
generate bos_aar = year(bos_dato)
generate bos_fylke = int(bos_kommune / 100)
assign-labels bos_kommune kommunelbl
assign-labels bos_fylke fylkelbl

// Botid i Norge (fra FORSTDATO) og i bosettingskommunen/etter bosetting, ved flytting til Skien
generate botid_norge = (flyttedato - forst_dato) / 365.25 if skien_idx > 0
generate botid_bos = (flyttedato - bos_dato) / 365.25 if skien_idx > 0 & kategori >= 2
// Grupper med formel (ikke recode/replace, som kan stoppes av avsløringskontrollen)
generate botid_norge_gr = 1 + (botid_norge >= 2) + (botid_norge >= 5) + (botid_norge >= 10) if !sysmiss(botid_norge)
generate botid_bos_gr = 1 + (botid_bos >= 2) + (botid_bos >= 5) + (botid_bos >= 10) if !sysmiss(botid_bos)
define-labels botidlbl 1 'Under 2 år' 2 '2 til under 5 år' 3 '5 til under 10 år' 4 '10 år eller mer'
assign-labels botid_norge_gr botidlbl
assign-labels botid_bos_gr botidlbl

// Innenfor tilskuddsperioden (5 år) og regjeringens forslag (10 år), regnet fra bosetting
generate innen_5_aar = botid_bos < 5 if !sysmiss(botid_bos)
generate innen_10_aar = botid_bos < 10 if !sysmiss(botid_bos)

// Fraflyttingskommuner med få personer slås sammen (avsløringskontroll)
generate en_flytter = skien_idx > 0
aggregate (sum) en_flytter -> n_fra_kommune, by(fra_kommune)
generate fra_kommune_gr = fra_kommune
replace fra_kommune_gr = 9998 if n_fra_kommune < $min_kommune
assign-labels fra_kommune_gr kommunelbl
